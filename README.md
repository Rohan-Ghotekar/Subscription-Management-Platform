# Subscription Management Platform

A full-stack Subscription Management Platform that enables users to discover and subscribe to plans, providers to manage subscription plans, and administrators to manage users, providers, subscriptions, payments, notifications, and analytics.

The platform includes role-based authentication, JWT security, email OTP verification, Stripe payments, Redis-based temporary OTP storage, AWS S3 file storage, automated subscription reminders, scheduled notification cleanup, email notifications, in-app notifications, and a production backend deployed on Amazon EC2 behind an Nginx HTTPS reverse proxy.

The OTP:

Redis is used for temporary OTP data instead of storing verification codes permanently in the relational database.

⏰ Automated Scheduler System

The backend contains scheduled background jobs that automatically handle subscription lifecycle operations and notifications.

The scheduler reduces manual intervention and automatically performs time-based operations.


🔔 7-Day Subscription Reminder

The system periodically checks active subscriptions that are approaching their expiry date.

For subscriptions expiring in 7 days, the system can:

Send an email reminder
Create an in-app notification
Track the reminder state
Prevent unnecessary duplicate reminders


🔔 1-Day Subscription Reminder

The system also checks subscriptions that are expiring in 1 day.

Users can receive:

Email reminder
In-app notification

Auto-renewing subscriptions are handled separately from manual-renewal reminders.

🗑️ Automatic Notification Cleanup

The platform automatically removes old read notifications.

A scheduled cleanup process checks for notifications that:

Have already been read
Were read more than 2 days ago

These notifications are automatically deleted.

Scheduled Cleanup
       │
       ▼
Find Read Notifications
       │
       ▼
Read Date > 2 Days?
       │
       ▼
     Delete

This helps:

Prevent unnecessary database growth
Keep notification data clean
Reduce unused records
Maintain relevant notification history
